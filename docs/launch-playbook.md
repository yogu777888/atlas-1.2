# tag.bet — плейбук запуска

## 1. Модель заработка

Партнёрские программы букмекеров платят тремя способами:

| Модель | Как платят | Когда брать |
|---|---|---|
| **CPA** | Фикс за игрока, сделавшего депозит (обычно $50–300, в США до $500+) | Новый сайт — деньги сразу |
| **RevShare** | 25–40% от чистого проигрыша игрока, пожизненно | Когда трафик стабилен — длинные деньги |
| **Hybrid** | Меньший CPA + меньший RevShare | Компромисс, часто лучший вариант |

Совет: начните с CPA/Hybrid, через 3–6 месяцев просите у менеджеров повышенные ставки по реальным цифрам.

## 2. Где брать партнёрки (Global EN)

- Прямые программы: bet365 Partners, Betfair Partnerships, Pinnacle Affiliates, Unibet (Kindred) Affiliates,
  Betway Partners, 888 Affiliates, William Hill Affiliates, 1xPartners, Stake Partners.
- Сети/агрегаторы: Income Access, NetRefer, MyAffiliates-кабинеты у операторов.
- Требования на входе: живой сайт с контентом, страницы responsible gambling и disclosure (уже есть),
  понятные источники трафика. Некоторые (bet365) проверяют жёстко — сначала наполните сайт.

После одобрения — ссылку в `.env` (`AFF_<SLUG>`), проверить `subIdParam`, сделать тестовый клик и
убедиться, что клик виден в кабинете партнёрки.

## 3. Трафик

1. **SEO** — главный канал для таких сайтов. Уже есть: страницы матчей, обзоры БК, sitemap, schema.org.
   Дальше: статьи «X vs Y prediction & odds», «best betting sites in <country>», «<bookmaker> bonus code».
2. **Контент в соцсетях** — X/Twitter, Telegram-канал с вилками и «best odds of the day» со ссылками на сайт.
3. **Приложение** — удержание: пользователь возвращается к сравнению каждый день.
4. Платная реклама гемблинга (Google/Meta) требует сертификации и лицензий — не на старте.

## 4. Юридическое (важно)

- **Не таргетируйте страны, где онлайн-беттинг запрещён или аффилиатам нужна лицензия.**
  Примеры: США (лицензия аффилиата в каждом штате), Франция, Австралия, Сингапур и т.д.
  Списки `blockedCountries` в `bookmakers.ts` — ваш первый рубеж; `/go` отправляет таких пользователей на
  страницу «недоступно в вашей стране».
- **UK**: реклама по правилам CAP/ASA — никакой ориентации на несовершеннолетних, ключевые условия бонуса
  рядом с оффером (карточки уже так устроены), аффилиат отвечает за рекламу оператора.
- **Раскрытие**: ссылки помечены `rel="sponsored"`, есть страница `/disclosure` (требование FTC и Google).
- **Privacy/Terms** — шаблоны, покажите юристу. Если будут посетители из ЕС — cookie-баннер понадобится,
  как только подключите аналитику с cookies.
- Юрлицо: партнёрки платят компаниям и ИП; популярные юрисдикции для аффилиатов — UK Ltd, Кипр, Мальта, Эстония.

## 5. App Store (не пропустите)

Apple, раздел 5.3 Review Guidelines (Gaming, Gambling, Lotteries):

- Приложение с азартной тематикой публикуется **от организации** (не от физлица) и получает рейтинг **18+**.
- Приложение **не принимает ставки** — только сравнение (так и сделано), это снижает требования.
- Ссылки на букмекеров в приложении — самый частый повод для реджекта. Поэтому:
  - при первой подаче можно выключить ссылки для всех стран через `APP_LINKS_DISABLED_COUNTRIES`
    и включить их после аппрува, по мере понимания позиции ревьюера;
  - ограничьте доступность приложения в App Store Connect странами, где это легально;
  - в Review Notes объясните: «odds comparison service, does not accept wagers, links only to licensed operators,
    geo-restricted, 18+ age gate».
- Возможно, потребуется подтвердить наличие лицензий/разрешений в странах распространения — держите
  документы готовыми.

## 6. Чек-лист до запуска

- [ ] Задеплоить `web/` на Vercel, подключить домен tag.bet
- [ ] Ключ The Odds API (платный тариф — бесплатного хватит только на тесты)
- [ ] Минимум 3 одобренные партнёрки, ссылки в env, тестовый клик виден в кабинете
- [ ] Заменить бонусы/промокоды/страны в `bookmakers.ts` на подтверждённые
- [ ] `CLICK_WEBHOOK_URL` → Google Sheets/БД, чтобы видеть клики по источникам
- [ ] Аналитика (Plausible/PostHog), Google Search Console + отправить sitemap
- [ ] Юрист: privacy, terms, список стран
- [ ] Apple Developer (организация) → TestFlight → App Store
