# tag.bet

Сайт сравнения коэффициентов **легальных российских букмекеров**: лучшая цена на каждый исход, вилки, рейтинг и бонусы.
Заработок — партнёрские программы букмекеров (с маркировкой рекламы) и реклама Яндекса.

```
web/         Next.js 16 — сайт tag.bet (русский язык)
prototypes/  прототипы игры «Созвездие» (отдельный бренд, не связан с tag.bet)
ios/         старое iOS-приложение (англ., под прежнюю версию API; для ставок в App Store не подходит)
docs/        плейбук запуска
```

## Сайт (web/)

```bash
cd web
cp .env.example .env.local   # заполните по мере готовности
npm install
npm run dev                  # http://localhost:3000
npm test                     # юнит-тесты математики коэффициентов
npm run build
```

Пока сайт работает на демо-коэффициентах (помечены «ДЕМО»). Живые коэффициенты российских букмекеров
подключим через sstats.net — см. `web/src/lib/odds/provider.ts`.

**Что есть:**

| Страница | Что делает |
|---|---|
| `/` | Лендинг: hero с живым сравнением, доска коэффициентов, рейтинг БК, бонусы, промо приложения, FAQ |
| `/odds`, `/odds?sport=…` | Все матчи, лучшая цена подсвечена, маржа, вкладка «Sure bets» |
| `/odds/[id]` | Матч: лучшие цены, таблица всех БК, калькулятор разбивки ставки для вилки |
| `/bookmakers`, `/bookmakers/[slug]` | Рейтинг и обзоры БК (SEO, schema.org Review) |
| `/bonuses` | Бонусы с условиями |
| `/go/[slug]?src=…` | **Трекер партнёрских кликов**: гео-блок, sub-id, лог, вебхук |
| `/api/v1/odds`, `/api/v1/bookmakers`, `/api/v1/config` | API для iOS |
| `/responsible-gambling`, `/disclosure`, `/privacy`, `/terms` | Обязательные страницы |

Плюс: 18+ age gate, sitemap.xml, robots.txt, OG-картинка, JSON-LD, security-заголовки.

### Как подключить партнёрку (обязательно с маркировкой)

По закону «О рекламе» партнёрская ссылка — это реклама, ей нужны токен erid и данные рекламодателя.
Для каждого букмекера задайте в переменных окружения три значения (см. `.env.example`):

```
AFF_FONBET=https://…      # ссылка из партнёрского кабинета (sub-id добавится сам)
ERID_FONBET=2Vtzq…        # токен из ОРД (оператора рекламных данных)
ADV_FONBET=ООО «…», ИНН … # рекламодатель — как указано в договоре
```

Пока все три не заданы, сайт вместо рекламной кнопки показывает ссылку на обзор, а `/go/<букмекер>`
не уводит на сайт букмекера. Так на сайте никогда не появится реклама без маркировки.
После изменения переменных сайт нужно пересобрать (redeploy): страницы собираются заранее.

⚠️ Рейтинги, маржа, плюсы/минусы и формулировки бонусов в `web/src/lib/bookmakers.ts` — заготовки.
Перед запуском сверьте букмекеров с реестром лицензий ФНС и впишите проверенные данные.
Не добавляйте офшорных букмекеров: за одну ссылку на них Роскомнадзор блокирует весь домен.

### Деплой

Подойдёт любой хостинг для Next.js: Vercel (Root Directory = `web`), Cloudflare или российский
хостинг (Timeweb, Selectel, Яндекс Облако). Задайте переменные окружения из `.env.example` и подключите домен `tag.bet`.

## iPhone-приложение (ios/)

Нужен Mac с Xcode 16+ и [XcodeGen](https://github.com/yonaskolb/XcodeGen):

```bash
brew install xcodegen
cd ios
xcodegen            # сгенерирует TagBet.xcodeproj
open TagBet.xcodeproj
```

- В Debug приложение ходит на `http://localhost:3000` (запустите `npm run dev`), в Release — на `https://tag.bet`.
- Впишите свой `DEVELOPMENT_TEAM` в `project.yml`, bundle id — `bet.tag.app`.
- Экраны: Odds (виды спорта, поиск, вилки, избранное), матч (лучшие цены, все БК, калькулятор вилки),
  Bonuses (копирование промокода), Books (рейтинг + обзоры), More (ответственная игра, раскрытие).
- Ссылки на БК открываются в in-app Safari и **выключаются удалённо** по стране через `/api/v1/config`
  (`APP_LINKS_DISABLED_COUNTRIES=US,FR`) — без обновления приложения. Это важно для ревью App Store.

> Код приложения написан под iOS 17 SDK, но в этой среде (Linux) не компилировался — первая сборка в Xcode
> может потребовать мелких правок.
